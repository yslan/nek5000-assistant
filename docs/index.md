# Nek5000 Assistant

**Publisher: Yu-Hsiang Lan**

A technical assistant for Nek5000 users in ChatGPT. It helps with building and
running the solver, case configuration, error diagnosis, performance and scaling,
I/O, and restarts. Answers reference official NekDoc documentation, existing
examples, source code, and relevant user discussions.

This independently maintained plugin provides instructions rather than a separate
server. There are no plugin payments or purchases. Public directory submission
is being prepared; availability in the directory is not yet approved.
