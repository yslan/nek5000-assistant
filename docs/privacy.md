# Privacy policy for Nek5000 Assistant

Publisher: **Yu-Hsiang Lan**. Updated: October 1, 2026.

## Plugin conversations

Nek5000 Assistant is a skills-only plugin running within ChatGPT. It has no
publisher-operated backend, external account system, payment system, or analytics
service. The plugin does not store user conversations or uploaded files outside
ChatGPT, and the publisher does not receive them through this plugin.

ChatGPT data handling, retention, and deletion are governed by OpenAI's policies
and your account settings. This policy does not change those arrangements.

## External sources and support

The assistant may reference public documentation, GitHub, and user discussions.
Visiting external links is subject to those services' policies.

If you voluntarily post a GitHub Issue, its contents and your public GitHub
identity are publicly visible. GitHub hosts and handles that information under
its own policies. Do not include sensitive or confidential information.

## Questions

Ask about this policy through
[GitHub Issues](https://github.com/yslan/nek5000-assistant/issues), without sharing
sensitive personal information. Manage ChatGPT conversation data through ChatGPT
and GitHub content through GitHub's controls.
