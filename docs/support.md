# Support for Nek5000 Assistant

Publisher: **Yu-Hsiang Lan**

For plugin problems, inaccurate instructions, or feature requests, open a
[GitHub Issue](https://github.com/yslan/nek5000-assistant/issues).

Include the plugin version, your Nek5000 version, a concise description, and a
minimal example or relevant error message. Remove secrets, personal information,
and confidential research data. Issues in this repository are public.

Support is provided through GitHub Issues; no response-time commitment is made.
