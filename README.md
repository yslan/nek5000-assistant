# Nek5000 Assistant

Maintained by **Yu-Hsiang Lan**. A skills-only technical assistant for
Nek5000 in ChatGPT, with documentation, examples, and source-code references.

## What it helps with

- Building and running Nek5000.
- Configuring cases and diagnosing simulation errors.
- Performance, scaling, I/O, and restarts.
- Finding documented parameters and relevant source implementations.

The assistant uses official [NekDoc](https://nek5000.github.io/NekDoc/),
the Nek5000 repository, and relevant user discussions. Independently maintained;
no institutional endorsement is implied.

## Support

Use this repository's [Issues](https://github.com/yslan/nek5000-assistant/issues).
Do not post credentials or confidential simulation data.

## Privacy and availability

The plugin does not operate a separate backend or store conversation data
outside ChatGPT. OpenAI governs ChatGPT data handling. Information you choose
to post in public GitHub Issues is visible publicly and handled by GitHub.
There are no plugin payments or purchases. Intended availability: all countries
offered by the publication platform, subject to that platform's availability.
